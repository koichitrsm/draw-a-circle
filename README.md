DRAW A CIRCLE — Creature Update
指で円を描くと、その線が生き物のように波打ち、周囲に檻のような線が現れて暴れ、最後に画面外へ飛び出して消えるミニアプリです。
使い方
`index.html` をブラウザで開く、またはGitHub Pagesで公開します。
画面上で指（PCではマウス）を使って円を描きます。
円が大きく変形し、2つの目が現れて生き物になります。檻のような線の中を素早く跳ね回ります。
最後にジャンプして画面外へ飛び出し、消えます。
`RESET` で最初からやり直せます。

外部ライブラリは使用していません。実機でのiPhone/Android動作確認は未実施です。
